# ForeCircle branding handoff

Use the Refined Original identity for the golfer and organizer experiences. The [brand guide](../branding/ForeCircle_Brand_Guide.pdf) and [brand notes](../branding/README.md) describe the approved palette, typography and applications.

- Use the supplied [transparent wordmark](../branding/ForeCircle_Logo_Transparent.png). The web copy is in `apps/web/public/brand/`.
- Keep the [source tokens](../branding/ForeCircle_Tokens.json) in sync with `packages/config/brand-tokens.json` and the web styles when changing the palette.
- Use Manrope for headings and Inter for body copy. The font files and license notices are included under `branding/fonts/`.
- Use ivory text on forest and charcoal text on fairway green. The [selected concept](../branding/reference/ForeCircle_Refined_Original.png) records the direction for future artwork.

See the [project status](STATUS.md) for production artwork and product follow-ups.
