# Roadmap and phase gates

0. Foundation — implemented source, schema/RLS and design preview; **blocked from completion by no dedicated Supabase project, unverified live Auth, and hosted RLS/security checks.**
1. Golfer community — connect validated adapters, real round/chat permissions, lifecycle, discovery, follows/My Circle. No production start until Phase 0 passes.
2. Circles — real membership/invites, Circle chat, role administration.
3. Organizer Mode — live activation, event management and honest derived metrics.
4. Tournaments — registration/waitlist, teams/flights, announcements, basic results, eligible ratings.
5. Organizer Lab — live submissions, voting/comments, status control, notifications, post-event feedback.
6. Growth — canonical public pages, production QR/share cards, referrals, owner marketing attribution.
7. Admin/hardening — controlled roles/audit, reports, moderation, rate limits, constrained uploads, performance and critical E2E suite.
8. SaaS launch — evidence-based readiness audit; remove demo data and enable indexing only for approved public content.
9. Native apps — Expo on the same stabilized backend.

The UI preview illustrates future phases; it does not move their completion gates. Payments, Circle dues, organizer subscriptions, leagues, course partnerships, sponsor commerce, push, handicap integrations and Wallet passes remain future work. Never enable unrestricted wagering.
